
# GTA 6: Vice Psychopath

2D top-down песочница в духе классических GTA, написанная на Python + Pygame.
Открытый мир, банды, полиция, миссии, боссы и чит-коды.

---

## Возможности

- **Открытый мир** 3200×2400 с дорогами, зданиями и шестью районами банд
- **Управление пешком и на машине** — десятки видов транспорта в потоке
- **Оружие** — пистолет, UZI, дробовик, AK-47; подбираются в домах
- **Полиция** — розыск до 15★, патрули, вертолёт, орбитальный удар
- **Боссы** — сутенёр с бандой, Васька Сморчков в двух фазах, танк, вертолёт
- **Миссии** — основная линия и сайд-задания, с целями разных типов
- **Стелс** — миссии, где нельзя оставлять свидетелей
- **Погода и время суток** — ясно, дождь, гроза; день и ночь
- **Чит-коды** — god, weapons, smorch, vice, noweather, notime
- **Динамическая камера** — приближение на скорости

## Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки | Ходьба и вождение |
| ЛКМ | Стрелять |
| F | Войти в дом / сесть в машину / снять девушку / подобрать ствол / старт миссии |
| J | Кидок проститутки / ×7 — сброс всех звёзд |
| Q | Сменить оружие |
| 1–4 | Радио в машине |
| H | Справка |
| R | Рестарт |
| Esc | Закрыть справку / выход с подтверждением |

## Чит-коды

Набираются прямо во время игры, как обычный текст.

| Код | Эффект |
|---|---|
| `god` | Режим бога |
| `mortal` | Выключить режим бога |
| `weapons` | Выдать всё оружие |
| `vice` | Спавн розовой тачки |
| `smorch` | Спавн босса Сморчка |
| `noweather` | Вкл/выкл погоду |
| `notime` | Вкл/выкл смену дня и ночи |

## Установка и запуск

**Требования:** Python 3.10+, Pygame 2.x.


pip install pygame
python main.py


Перед первым запуском убедись, что папка `assets/` на месте и содержит
все спрайты (см. раздел «Структура проекта»).

---

## Сборка в .exe

В корне проекта лежит `build.bat`. Установи PyInstaller один раз:


pip install pyinstaller

Затем запусти `build.bat` — готовый файл появится в `dist/`.

На Linux/macOS запускай команду из `build.bat` вручную, заменив
разделитель `;` на `:` в аргументе `--add-data`.

## Рабочий процесс обновлений

Изменения в проекте вносятся через папку `forUpdate/` — она позволяет
аккуратно применять патчи, не теряя старые версии файлов.


forUpdate/
├── newFix.txt              — описание фиксов и полные тексты файлов
└── workScripts/
    ├── makeNewFiles.py     — разворачивает файлы из newFix.txt в forUpdate/
    └── copyNewFiles.py     — копирует файлы из forUpdate/ в проект


Порядок применения патча:

1. Сохранить ответ с фиксами в `forUpdate/newFix.txt`.
2. `python forUpdate/workScripts/makeNewFiles.py`
3. Проверить глазами, что развернулось в `forUpdate/`.
4. `python forUpdate/workScripts/copyNewFiles.py`
5. Запустить игру.

Перезаписанные файлы сохраняются с расширением `.bak`.

## Добавление новой миссии

Миссии — это данные. Чтобы добавить миссию, достаточно дописать объект
`Mission` в список `MISSIONS` в `missions/data.py`. Движок сам решит,
когда стартовать, как считать прогресс и что делать при провале.

Пример:


Mission(
    id="my_mission",
    title="Название",
    brief="Краткое описание",
    start_pos=(1000, 1000),
    is_main=False,
    repeatable=True,
    stages=[
        Stage(Reach((2000, 2000), radius=70), hint="Доедь до метки"),
        Stage(Kill("gangster", count=2), hint="Убей двух бандитов"),
    ],
    reward=Reward(money=1500),
    fail_policy="RETRY",
)


Доступные типы целей: `Reach`, `Kill`, `Steal`, `Survive`.
Новые типы добавляются в `missions/objectives.py` — один класс,
два обязательных метода (`is_done`, `progress`) и опциональные хуки
(`on_start`, `on_update`, `on_cancel`, `on_kill`).
